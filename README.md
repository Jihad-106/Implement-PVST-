# Implement PVST+

## Overview

This project demonstrates Per-VLAN Spanning Tree Plus (PVST+) using Cisco Packet Tracer.

## Topology

The topology contains multiple Cisco 2960 switches with redundant links to demonstrate STP/PVST+ loop prevention.

## Technologies Used

- Cisco Packet Tracer
- VLAN
- Trunking
- PVST+
- Spanning Tree Protocol (STP)

## VLANs

- VLAN 10
- VLAN 20
